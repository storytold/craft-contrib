# craft-contrib

This repository holds the Craft suite's RFCs (`rfcs/`) and standards (`standards/`). It has no application code. [README.md](README.md) describes the layout and the decision process.

- `standards/app-agents.md` is the shared text that the Craft app and library repositories copy into their own `AGENTS.md`. Its rules are for work in those repositories, not this one.
- Changing an accepted RFC or a standard follows [RFC-0000](rfcs/0000-decision-process.md) and [RFC-0013](rfcs/0013-amending-rfcs.md).
